Welcome, Underwriter. Select a loan application from the queue on the left to begin. This prototype walks each deal through the three stages of cognitive computing — Perception (document intake & extraction), Learning (historical pattern matching), and Reasoning (risk synthesis) — with you holding final decision authority at every step.
This is a concept-validation prototype built for user testing. All borrowers, financials, and historical deals are fictional. AI analysis is generated in real time and reviewed by a human underwriter before any decision is recorded. The system recommends — it never approves.

Requirements Traceability — 15 User Stories

Perception

P1 — Ingest and process all borrower-submitted documents regardless of file format.
P2 — Consolidate documents into a single, organized, reviewable package.
P3 — Extract key financial data points from unstructured materials.
P4 — Flag missing information and block analysis until the package is complete.
P5 — Incorporate approved alternative data sources.

Learning

L1 — Identify patterns across historical loan data correlated with actual outcomes.
L2 — Surface similar historical deals and how they performed.
L3 — Learn only from outcome-validated historical decisions.
L4 — Capture judgment criteria from experienced underwriters.
L5 — Flag deals with limited historical precedent.

Reasoning

R1 — Synthesize data, patterns, and risk factors into a preliminary assessment.
R2 — Generate a risk rating with justification traceable to evidence.
R5 — Apply consistent, institutionally agreed decision criteria.
R6 — Generate a written assessment as the audit trail.
R7 — Final decision authority remains with the underwriter.

Add products from the catalog

Programmatic

5.4

Configure product-level pricing

Agentic

The agent reasons through which pricing model applies to each product, calls the pricing rules tool, and calculates tier by tier. Then the rep can adjust anything manually — license count, platform price — and the quote recalculates. Rep judgment beats agent output.

5.5

Apply quote-level adjustments

Agentic

The agent checks discount policy, reasons about what applies — and what doesn't stack — and recommends. Every recommendation is a checkbox the rep can flip. And if the rep has their own idea, they can add a custom adjustment the agent never suggested.

5.6

Review, finalize & submit

Human decision

The agent generates a plain-language summary of the full quote. The rep reviews it and has two paths for changes: describe the change in a prompt and let the agent route them to the right step, or reopen any step and edit manually. Either way, the rep submits — the agent never does.
